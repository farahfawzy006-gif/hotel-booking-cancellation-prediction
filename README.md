# Hotel Booking Cancellation Prediction

## Project Overview
This project focuses on preparing a hotel bookings dataset for a hotel booking cancellation prediction model.

The initial commit contains the complete data preprocessing pipeline. Future updates may include model training, evaluation, and performance analysis.

## Dataset
Hotel Bookings Dataset

## Preprocessing Steps
- Performed exploratory data analysis (EDA)
- Handled missing values
- Removed duplicate records
- Treated outliers
- Performed feature engineering
- Encoded categorical variables
- Removed data leakage columns
- Split the dataset into training and testing sets
